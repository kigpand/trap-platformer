## 완료된 릴리스 — 새 맵 추가
1~4주 차 로드맵 항목은 모두 끝났습니다. 함정의 "학습 가능" 규칙을 확정하면서(`docs/traps-spec.md` "공통 규칙") 남았던 MVP 요건(가짜 안전지대의 사망 후 표시)도 아래 1번으로 채워, **MVP 완료 기준을 모두 충족합니다.**

이 릴리스는 이 MVP 요건을 먼저 채운 뒤 레벨을 여러 개로 늘리는 것을 목표로 하며, 아래 순서로 진행합니다. 각 항목은 별도 PR로 만들고, 완료 기준을 모두 만족해야 체크합니다.

1. [x] **가짜 안전지대 사망 후 표시** (MVP 요건) — `docs/traps-spec.md` #4의 텔레그래프 규칙 구현.
   - 완료 기준: 가짜 안전지대로 사망하면 재시작 후 해당 타일이 강조 표시되고(타일이 화면에 보이는 동안 2초), 다른 원인의 사망·수동 재시작(R)에서는 표시되지 않는다. 현재 레벨의 체크포인트는 점프로 건너뛸 수 없어 재시작 화면 안에서 바로 보인다.
   - 테스트:
     - `World` 단위 테스트 — 표시 상태의 시작·2초 후 해제·R로 해제·다른 사망 원인은 표시 안 함.
     - `CanvasRenderer` 단위 테스트 — 그리기 호출을 기록하는 가짜 2D 컨텍스트로, 표시 상태일 때 해당 타일 영역에 강조 색이 그려지고 표시가 끝나면 일반 바닥과 같게 그려지는지 확인(`World` 상태만으로는 실제 화면 표시를 검증할 수 없다).
     - 개발 서버에서 실제 사망 후 강조 표시 화면 확인(스크린샷을 PR에 첨부).
2. [x] **레벨 데이터 구조 개편** — `level.ts`의 전역 상수를 레벨 객체(지형·함정·적·체크포인트·스폰·목표)로 묶고, `World`가 레벨을 인자로 받게 한다. 동작 변화 없는 리팩터링.
   - 완료 기준: 기존 레벨이 새 구조로 옮겨지고 기존 단위·E2E 테스트가 수정 없이(또는 레벨을 넘기는 부분만 바꿔) 통과한다.
   - 테스트: 기존 테스트 전체, 특히 텔레포트 없는 스폰→목표 자동 플레이 테스트.
3. [x] **새 레벨 1개 추가** (`LEVEL_2` — 낙하 발판 징검다리·갑자기 출현하는 적·가짜 안전지대 + 왕복 적, `tests/unit/world/Level2.test.ts`) — 함정 5종 중 최소 3종과 적을 레벨 1과 다른 조합으로 배치. `docs/physics-spec.md`의 "레벨 배치 제약"을 지킨다. 진행 흐름(4번) 전이라 게임 화면에서는 아직 선택할 수 없고, 2번의 구조 덕분에 `World`에 직접 넘겨 테스트한다.
   - 완료 기준: 새 레벨 객체로 만든 `World`에서 텔레포트 없는 스폰→목표 자동 플레이 테스트가 통과하고, 각 함정이 학습 가능 요건을 만족한다.
   - 테스트: 새 레벨의 도달 가능성 자동 플레이 테스트, 함정별 트리거 테스트.
4. [x] **레벨 진행 흐름** (버튼·N 키로 진행, 레벨 선택 화면 없음, 마지막 레벨 뒤 완료 화면에서 레벨 1부터 — 결정 사항은 `docs/game-design.md` "레벨 진행") — 클리어 후 다음 레벨로 넘어가기, 현재 레벨 표시(HUD), 최고 기록을 레벨별로 저장. 3번의 새 레벨을 실제로 플레이할 수 있게 연결한다.
   - 완료 기준: 레벨 1 클리어 → 레벨 2 시작, 마지막 레벨 클리어 시 완료 화면, 기존 저장 기록(`trap-runner:best`)은 레벨 1 기록으로 이어진다.
   - 테스트: 진행 흐름 단위 테스트, 레벨별 기록 저장 테스트, 다음 레벨 전환 E2E.
   - 착수 전 결정: 레벨 선택 화면 유무, 다음 레벨로 자동 진행할지 버튼으로 진행할지.

"새 맵 추가" 릴리스는 완료됐습니다. 이번 릴리스는 처음엔 뒤통수를 치지만 원인을 알면 피할 수 있는 함정 8종(`docs/traps-spec.md` 6~13번)을 더하고, 레벨을 더 길게 만드는 것이 목표입니다(프로젝트 오너 결정: 함정 7종 선택 후 "하늘에서 쏟아지는 적"(13번)을 적 중력 규칙 변경과 함께 추가, 기존 레벨 1·2를 늘리고 레벨 3 추가). 각 항목은 별도 PR이며 완료 기준을 모두 만족해야 체크합니다.

1. [x] **엔진 기반: 사망 원인 표시 일반화 + 긴 맵 배경** — 가짜 안전지대 전용인 사망 후 표시(`World.hazardReveal`)를 모든 함정의 "사망 원인 표시"로 넓히고(낙사형 함정은 사망 직전 3초 안에 발동한 함정을 원인으로 봄), 배경 건물을 레벨 폭에 맞춰 반복해 그린다(지금은 약 2,340px까지만 그려짐).
   - 완료 기준: 기존 가짜 안전지대 동작이 그대로 유지되고, 기존 함정 1~3·5번과 일반 왕복 적도 `traps-spec.md` "사망 원인 표시" 규칙대로 표시된다(낙사형 1·2번은 3초 규칙). 새 함정은 같은 공통 경로로 원인을 넘기기만 하면 된다. 레벨 폭이 늘어도 배경이 끝까지 그려진다.
   - 테스트: 기존 `World`·`CanvasRenderer` 테스트 유지, 기존 함정·적별 원인 표시 단위 테스트, 사망 원인 3초 규칙(3초 안 발동 → 표시, 3초 밖·발동 없는 낙사 → 표시 안 함) 단위 테스트, 넓은 레벨에서 배경이 화면 끝까지 그려지는지 렌더러 테스트.

   - 완료 기준: 각 함정이 `traps-spec.md`의 트리거·동작·실패 결과대로 동작하고, 사망 시 원인 표시가 된다.
   - 테스트: 함정별 `World` 단위 테스트(트리거·동작·실패·회피 해법), 렌더러 테스트(경고·등장 표시).
