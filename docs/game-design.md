# 게임 설계 (최소 기능 제품, MVP)

## 콘셉트
의도적으로 예상 밖의 상황을 만들지만 학습을 통해 대처할 수 있는 위험 요소를 갖춘 독자적인 픽셀 스타일 2D 횡스크롤 함정 플랫포머입니다. 현재 프로토타입은 완성된 스프라이트 대신 단순한 도형을 사용합니다.

## 조작
- ←/→ 방향키 또는 A/D: 이동
- Space, ↑ 또는 W: 점프 (키를 새로 누르는 순간에 실행)
- R: 레벨 재시작
- B: 충돌 디버그 오버레이 표시 전환

## MVP 완료 기준
- 시작 지점과 목표가 명확한 플레이 가능한 레벨
- 안정적인 이동·점프·착지 및 단단한 플랫폼과의 충돌
- 플레이어 사망과 즉시 재도전
- 학습 가능한 사전 신호가 있는 서로 다른 함정 최소 5종
- HUD와 소리 켜기/끄기 기능, 재시작 시 브라우저 오류 없음
- 독자적인 시각·음향 자료와 키보드 지원

## 범위와 제한
- 데스크톱 키보드를 우선 지원하며, 반응형 터치 및 게임패드 지원은 추가 목표입니다.
- 초기 `src/game/world/level.ts`는 완성된 레벨이 아닌 **테스트용 공간**입니다.
- Super Mario Bros.의 레벨 배치나 캐릭터를 그대로 재현하지 않습니다.
- 함정 작동 시점과 적의 동작 규칙은 `docs/traps-spec.md`에 정의되어 있습니다.
