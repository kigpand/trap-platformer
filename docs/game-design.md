# 게임 설계 (최소 기능 제품, MVP)

## 콘셉트
의도적으로 예상 밖의 상황을 만들지만 학습을 통해 대처할 수 있는 위험 요소를 갖춘 독자적인 픽셀 스타일 2D 횡스크롤 함정 플랫포머입니다. 플레이어·적은 코드로 정의한 픽셀 스프라이트와 걷기 애니메이션을 사용하며, 지형·함정·목표 등은 아직 단순 도형입니다.

## 조작
- ←/→ 방향키 또는 A/D: 이동
- Space, ↑ 또는 W: 점프 (키를 새로 누르는 순간에 실행)
- R: 레벨 재시작
- B: 충돌 디버그 오버레이 표시 전환
- P: 일시정지/재개 (탭이 백그라운드로 가면 자동 정지, 자동 재개는 하지 않음)
- M: 소리(효과음·배경 음악) 켜기/끄기
- N: 레벨을 클리어한 뒤 다음 레벨로(화면의 "다음 레벨" 버튼과 같음). 마지막 레벨을 클리어하면 완료 화면의 "레벨 1부터 다시" 버튼과 같음
- 음량 슬라이더: 효과음과 배경 음악의 전체 음량(0~100%, 기본 80%). 음소거와 별개로 저장되어 음소거를 풀면 이전 음량으로 돌아옴
- 터치 기기: 캔버스 아래의 ◀/▶ 버튼을 누르고 있는 동안 이동, ▲ 버튼으로 점프(누르는 순간에 실행). 터치 버튼은 `pointer: coarse` 기기에서만 표시되며, 정지·재시작·음소거는 기존 버튼을 사용

## 기록
- HUD의 TIME은 이번 런의 경과 시간입니다. 일시정지 중에는 흐르지 않고, 클리어하면 멈춥니다.
- 런은 수동 재시작(R)으로만 새로 시작합니다. 사망하면 체크포인트에서 이어 가며 시간도 계속 흐릅니다.
- 최고 기록(BEST)은 레벨마다 따로 저장하며, 최단 클리어 시간과 최소 사망 수를 각각 따로 갱신합니다. 브라우저에 저장되어 새로고침 후에도 유지됩니다. 맵 3배 확장으로 레벨이 길어져 예전(짧은 맵) 기록은 이어받지 않고 새로 시작합니다. 같은 브라우저의 다른 탭에서 기록을 갱신하면 열려 있는 탭의 BEST 표시에도 새로고침 없이 바로 합쳐집니다.

## 레벨 진행
- 게임은 항상 레벨 1부터 시작합니다(레벨 선택 화면 없음).
- 레벨을 클리어하면 기록을 확인한 뒤 "다음 레벨" 버튼이나 N 키로 넘어갑니다(자동으로 넘어가지 않음). 새 레벨에서는 시간·사망 수(FALLS)·체크포인트를 새로 셉니다.
- 마지막 레벨을 클리어하면 "모든 레벨 클리어" 완료 화면에 레벨별 최고 기록을 보여 주고, 버튼(또는 N)으로 레벨 1부터 다시 시작합니다.
- **난이도 곡선**(프로젝트 오너 결정): 레벨이 올라갈수록 길어지고 함정이 많아지며 타이밍이 빡빡해집니다.
  - 레벨 1(쉬움, 12,000px): 원래 함정 뒤에 새 함정 4종(사라지는 땅·떨어지는 천장·솟아오르는 가시·도망가는 발판)을 구간마다 하나씩 소개하고, 점프 여유를 넉넉히 줍니다(예: 좁은 16px 가시 — 트리거 앞 출발 구간 34px). 맵 3배 확장으로 예전 목표 자리(3,940px)는 가짜 클리어가 되고, 그 뒤로 약올리는 함정을 하나씩 소개합니다 — 미끼 보물(구덩이) → 내려오는 천장 통로와 끝을 막은 듯한 가짜 벽 → 얼음 → 박자 발판 2개 → 따라 하는 그림자 → 목표 직전 스프링 바닥. 가짜 표지판은 가짜 클리어·얼음·스프링 앞에 둡니다.
  - 레벨 2(보통, 15,300px): 새 함정 7종을 모두 쓰고(투명 블록·가시·가짜 체크포인트·사라지는 땅·떨어지는 천장·도망가는 발판·도망가는 목표), 왕복 적을 하나 더 둡니다. 맵 3배 확장으로 도망가는 목표 구간을 레벨 끝으로 옮기고, 그 사이에 레벨 1에서 쓰지 않은 약올리는 함정을 하나씩 둡니다 — 날려버리는 점프 → 좌우 반전 → 무거운 신발 → 착지 예측 가시 → 화살(낮은 것·높은 것) → 따라 뛰는 적 → 세 번째 착지 발판(발끝까지 버티다 늦게 뛰어야 두 번만 착지) → 따라오는 돌덩이. 출발 구간은 레벨 1보다 좁습니다(24px 가시 26px, 높이 50px 가짜 체크포인트 29px, 투명 블록을 피하는 이른 점프 43px — 모두 시뮬레이션 실측).
  - 레벨 3(어려움, 16,800px): 하늘에서 쏟아지는 적을 포함한 새 함정 8종 전부를 명세 기본 크기로 쉴 틈 없이 이어 붙입니다(사라지는 땅 직후 가시, 천장 착지 직후 가시처럼 함정이 연달아 나옴). 출발 구간은 40px 가시 10px, 높이 60px 가짜 체크포인트 12px, 투명 블록을 피하는 이른 점프 23px입니다(시뮬레이션 실측). 맵 3배 확장으로 마지막 구간(도망가는 목표)을 끝으로 옮기고, 그 사이에 14~30번을 둘씩 섞어 둡니다 — 돌덩이와 길 가운데 가짜 벽, 얼음 끝의 날려버리는 점프, 그림자 안의 좌우 반전, 화살 세 발 뒤 무거운 신발, 따라 뛰는 적 뒤 "여기서 점프!" 표지판과 착지 예측 가시, 세 번째 착지 발판, 박자 발판 세 개와 미끼 보물, 더 빠른 내려오는 천장과 "진짜 끝!" 두 번째 가짜 클리어, 스프링.

## 소리
- 효과음(점프·사망·체크포인트·클리어)과 배경 음악은 모두 외부 음원 없이 Web Audio로 합성한 독자적인 소리입니다.
- 배경 음악은 4마디 루프이며, 게임이 진행 중일 때만 재생됩니다. 일시정지(탭이 백그라운드로 가서 자동 정지된 경우 포함)나 음소거 중에는 멈추고, 재개하면 멈춘 지점부터 이어집니다.
- 음소거와 음량 설정은 브라우저에 저장되어 새로고침 후에도 유지됩니다.

## 놀리는 사망 메시지
함정에 죽으면 재시작 직후 2초 동안 캔버스 위쪽에 그 함정을 놀리는 한 줄을 띄웁니다(프로젝트 오너 결정). 사망 원인 표시(`docs/traps-spec.md` "공통 규칙")와 함께 나와 "무엇에 당했는지"를 웃기게 알려 주는 연출이며, 스크린 리더 사망 알림에도 같은 문장을 덧붙입니다. 원인이 없는 낙사(그냥 구덩이에 빠짐)에는 띄우지 않습니다. 문구는 이 게임용으로 새로 쓴 것이며 `src/game/rendering/taunts.ts`에 있습니다.

## MVP 완료 기준
- 시작 지점과 목표가 명확한 플레이 가능한 레벨
- 안정적인 이동·점프·착지 및 단단한 플랫폼과의 충돌
- 플레이어 사망과 즉시 재도전
- 학습 가능한 서로 다른 함정 최소 5종(사전 경고가 있거나, 처음엔 숨겨져 있더라도 사망 직후 원인을 표시 — `docs/traps-spec.md` "공통 규칙")
- HUD와 소리 켜기/끄기 기능, 재시작 시 브라우저 오류 없음
- 독자적인 시각·음향 자료와 키보드 지원

## 범위와 제한
- 데스크톱 키보드를 우선 지원합니다. 터치 기기에서는 화면의 이동·점프 버튼으로 플레이할 수 있으며, 게임패드 지원은 추가 목표입니다.
- `src/game/world/level.ts`의 `LEVEL_1`은 시작-목표가 있고 함정 5종·적·체크포인트에 새 함정 4종 구간과 약올리는 함정 구간을 이어 붙인 12,000px 레벨입니다. `LEVEL_2`는 다른 함정 조합(낙하 발판·갑자기 출현하는 적·가짜 안전지대 + 왕복 적) 뒤에 새 함정 7종 구간과 약올리는 함정 구간을 이어 붙인 15,300px 레벨, `LEVEL_3`은 새 함정 8종 구간 뒤에 14~30번을 섞은 구간을 이어 붙인 16,800px 마지막 레벨이며, `LEVELS` 순서대로 이어서 플레이합니다. 지형·함정·목표는 여전히 단순 도형(임시 에셋)입니다.
- Super Mario Bros.의 레벨 배치나 캐릭터를 그대로 재현하지 않습니다.
- 함정 작동 시점과 적의 동작 규칙은 `docs/traps-spec.md`에 정의되어 있습니다.
