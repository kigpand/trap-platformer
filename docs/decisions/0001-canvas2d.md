# ADR-0001: MVP에 Canvas 2D 사용

상태: 승인됨

## 배경
이 게임은 2D 횡스크롤 함정 플랫포머입니다. 목표는 렌더링과 시뮬레이션의 경계 및 AI 지원 작업 흐름을 이해하는 것이며, 3D 렌더링을 선보이는 것이 아닙니다.

## 결정
TypeScript와 CanvasRenderingContext2D를 사용하고, 렌더러를 물리 로직과 분리합니다. React는 외곽 UI와 HUD에 사용하며, 프레임별 그리기에는 사용하지 않습니다.

## 영향
입력, 카메라, 충돌, 렌더링 등 엔진이 담당할 책임은 늘어나지만 의존성 범위는 줄어듭니다. 측정으로 렌더러 병목이 확인되거나 시각적 요구 사항이 생긴 뒤에만 WebGL을 다시 검토합니다.
