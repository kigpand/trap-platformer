# 게임플레이 기능 구현
1. AGENTS.md와 관련 문서를 읽습니다.
2. 완료 기준과 영향을 받는 모듈을 나열합니다.
3. 대표적인 경계 사례를 포함해 테스트를 추가하거나 갱신합니다.
4. 기준을 충족하는 최소한의 해결책을 구현합니다.
5. 프로젝트 검사를 실행하고 실제 결과를 기록합니다.
6. 변경 범위, 재현 방법, 남아 있는 위험을 포함해 짧은 Codex 리뷰 인계 내용을 제공합니다.
범위가 정해진 게임 기능을 요청받았을 때 사용합니다. 프로젝트 결정을 우회하거나 누락된 게임플레이 규칙을 임의로 만드는 데 사용하지 않습니다.
