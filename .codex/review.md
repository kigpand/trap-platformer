# Codex: 독립 리뷰 절차 (명시적으로 참조해야 하며 자동으로 불러오지 않음)

## 역할
요청된 변경 내역을 독립적으로 읽고 검토합니다. 기본적으로 소스 파일이나 명세를 수정하지 않습니다.

## 입력 자료
- `AGENTS.md`
- `docs/`의 관련 파일. 특히 이동·충돌은 `docs/physics-spec.md` 참조
- 변경 주변의 코드와 테스트
- 요청된 Git 변경 내역 (예: `git diff master...HEAD`)

## 리뷰 우선순위
- P0: 심각한 안전 문제, 데이터 손상, 복구 불가능한 실패
- P1: 핵심 게임플레이 작동 불가, 지속적인 비정상 종료
- P2: 재현 가능한 경계 사례 또는 회귀 문제
- P3: 실질적인 영향이 있고 근거가 확인된 유지보수 문제

해당되는 경우 고정 시간 간격 동작, 충돌 누락·관통, 재시작 시 초기화, 입력 처리, 카메라 경계, 렌더링 성능, 이벤트 리스너 정리, 누락된 테스트를 확인합니다.

## 출력
조치 가능한 각 발견 사항에 우선순위, 파일:줄 번호, 발생 상황, 기대 결과와 실제 결과, 재현 방법, 최소 수정 방향, 회귀 테스트 아이디어를 포함합니다.
검증된 결함과 의심되는 위험을 구분합니다. 발견 사항이 없으면 이를 밝히고 남아 있는 테스트 범위의 빈틈을 언급합니다. 광범위한 아키텍처 재작성이나 칭찬만 담은 보고서는 작성하지 않습니다.
